# Kotlin 

This is a simple Kotlin program that prints **"Hello, Android!"** to the console.  
It serves as a starting point for learning Kotlin syntax and structure.

## Prerequisites

- **Java Development Kit (JDK)** 8 or higher  
- **Kotlin Compiler** (can be installed via [Kotlin website](https://kotlinlang.org/docs/command-line.html) or using IntelliJ IDEA)
- A text editor or IDE (e.g., IntelliJ IDEA, VS Code)

## Program

```kotlin
// File: HelloWorld.kt
fun main(args: Array<String>) {
    println("Hello, World!")
}
